# TaskFlow | برنامه مدیریت وظایف (Todo App)

پروژه درس مهندسی نرم‌افزار — فاز اول (اسپرینت اول)

این پروژه یک برنامه کاربردی تحت وب برای مدیریت وظایف است که با استفاده از چارچوب توسعه اسکرام (Scrum) و به صورت تیمی (تفکیک فرانت‌اند و بک‌اند) پیاده‌سازی شده است.

## 🛠️ پشته فناوری (Tech Stack)

- **فرانت‌اند (Frontend):** Next.js 14 (App Router), TypeScript, CSS
- **بک‌اند (Backend):** Node.js, Express.js, TypeScript
- **پایگاه داده (Database):** PostgreSQL (میزبانی‌شده روی Neon)
- **ابزار ارتباط با دیتابیس (ORM):** Prisma 6
- **اعتبارسنجی (Validation):** Zod (در هر دو سمت کلاینت و سرور)

---

## 📂 ساختار پروژه

- `frontend/` : کدهای سمت کلاینت (رابط کاربری)
- `backend/` : کدهای سمت سرور (API)
- `docs/` : مستندات کامل اسکرام (بک‌لاگ‌ها، گزارش جلسات، معیارهای تکمیل)

---

## 🚀 راهنمای نصب و اجرا

برای اجرای این پروژه، به دو ترمینال جداگانه نیاز دارید (یکی برای بک‌اند و یکی برای فرانت‌اند).

### پیش‌نیازها
- Node.js (نسخه ۲۰ یا بالاتر)
- npm (مدیر بسته نود جی‌اس)
- دسترسی به یک پایگاه داده PostgreSQL (یا استفاده از دیتابیس ابری Neon)

---

### گام ۱: راه‌اندازی بک‌اند (Backend)

ترمینال اول را باز کنید و دستورات زیر را به ترتیب اجرا کنید:

```bash
# ۱. ورود به پوشه بک‌اند
cd backend

# ۲. نصب پکیج‌های مورد نیاز
npm install

# ۳. همگام‌سازی دیتابیس و ساخت جداول
npx prisma generate
npx prisma migrate dev

# ۴. اجرای سرور بک‌اند
npm run dev

# ۱. ورود به پوشه فرانت‌اند
cd frontend

# ۲. نصب پکیج‌های مورد نیاز
npm install

# ۳. اجرای سرور فرانت‌اند
npm run dev
